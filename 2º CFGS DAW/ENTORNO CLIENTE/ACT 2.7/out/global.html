validarDNI(numeroDNI, letra) → {boolean}

Calcula el resto de dividir el número entre 23 y comprueba que la letra de esa posición en la tabla oficial coincida con la indicada. No distingue entre mayúsculas y minúsculas.
Parameters:
Name Type Description
numeroDNI number Parte numérica del DNI (entero entre 0 y 99999999).
letra string Letra de control a verificar (una sola letra).
Source:
  • comentarios.js, line 21
Throws:
  • Si `numeroDNI` no es un número entero o `letra` no es un string.
    Type
    TypeError
  • Si `numeroDNI` es negativo o supera los 8 dígitos.
    Type
    RangeError
Returns:
`true` si la letra es la correcta para ese número; `false` en caso contrario.
Type
boolean
Example
validarDNI(12345678, "Z"); // true
validarDNI(12345678, "a"); // false
