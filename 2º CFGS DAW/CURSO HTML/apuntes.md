<html lang="en">
elemento: html
atributo: lang (language --> Inglés)
elemento meta con atributo charset: tipo de caracteres que usará nuestra página

ELEMENTOS EN BLOQUE Y ELEMENTOS EN LÍNEA

en bloque: elemento que ocupa todo el ancho de su contenedor (h1, p)
en línea: elemento que ocupa el ancho de su contenido (span)

- Para texto normalmente: p

- Para títulos normalmente: h1 - h6
En una pág web solo debe haber un h1 (buena práctica)
No se debe saltar de un h1 a un h4 sin usar un h2 o h3.

- Para resaltar texto en parrafos: span

Dentro de elementos ul solo deben haber elementos li
